🗑️ Smart Trash Bin

A real-time trash monitoring system built with Arduino and Raspberry Pi
This README was generated with the help of AI.

🚀 Overview

The Smart Trash Bin is a low-cost, efficient solution designed to detect trash levels and send alerts before bins overflow. Using an ultrasonic sensor connected to an Arduino, the system measures how full the bin is and communicates that information to a Raspberry Pi, which sends notifications to cleaning staff.

This project focuses on improving city cleanliness, reducing unnecessary labor, and enhancing waste-management efficiency.

🔧 Technologies Used

Arduino Uno – Reads sensor data

Ultrasonic Sensor – Measures bin fill distance

Raspberry Pi – Processes data + sends alerts

Arduino IDE – Coding for Arduino

Python – Serial communication + logic on Raspberry Pi

💡 How the System Works

Ultrasonic Sensor calculates distance between trash and sensor

Arduino determines whether the bin is OK, NEAR FULL, or FULL

Raspberry Pi receives this data via serial connection

The Pi sends real-time alerts to the cleaning staff
